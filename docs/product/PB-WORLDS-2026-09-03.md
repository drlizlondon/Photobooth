## 0. Ground truth (read-only survey 2026-09-03 — cite before changing)

- **The raw camera has exactly three consumers.** (1) the `<video id="video">` element itself, shown directly (`index.html:599`, CSS `styles.css:318-319`); (2) `capturePhoto()` — `ctx.drawImage(v,…)` on `#captureCanvas` → JPEG data URL (`app.js:1687-1698`); (3) `freezeCameraFrame()` — copies the video to an offscreen canvas for the Moving Polaroid (`app.js:1699-1704`), which `captureMovingPolaroid()` also hands live to `compositor.drawLive(ctx,video)` (`app.js:1806`). **One "frame source" seam covers all three. That is the whole integration.**
- **Mirror is applied in three places** and must stay untouched: CSS class `.mirror` on the video (`app.js:1642`, `styles.css:319`), a canvas transform at capture (`app.js:1692`, `:1710`), and the `mirror:` option into `Polaroid.composeLive` (`app.js:1769`). **Design consequence (§2.3):** the composited world canvas must be a *drop-in for the video element in the video's own coordinate space* — person unflipped, world pre-flipped when mirror is on — so every existing mirror path applies unchanged and the world ends up reading correctly.
- **Camera lifecycle:** `startCamera(sessionId)` (`app.js:1632-1650`) acquires `facingMode:"user"`, ideal 1920×1080, plays, sets `sessionOrientation` (`:1648`). `stopCamera()` (`:1651`). Everything is guarded by `sid!==captureSessionId` cancellation checks — new async work must keep those guards.
- **The guest never chooses anything before capture today.** `beginSession()` (`app.js:1830-1925`) runs: `startCamera` → 400ms → prompts/countdown/`capturePhoto()` × 3 (strip / shared) or × 1 (magazine), or `captureMovingPolaroid` (polaroid) → `stopCamera` → gallery save → review. Guest creative choices (frame, filter) happen **after** capture in review (`buildReviewControls`, `app.js:2003`). A live world picker is therefore a **new pre-countdown phase inside the existing camera screen**, not a new screen.
- **Entry points into `beginSession`:** `enterGuestBooth()` (`app.js:3361`, wired to `#startBtn` at `:3424`), `launchFreeBooth()` (`:2986`), host test `beginSharedSession(false,{purpose:"host-test"})` (`:2926`, the **TEST CAMERA & OUTPUTS** button `#previewEventBtn`), `#nextGuestBtn` (`:3430`), retake (`restartCurrentSession`, `:1928`). `purpose==="host-test"` is the existing showcase path (`isHostTest`, `:1832`) — **this is where "demonstrate as admin whenever I want" lives.**
- **Strip crops the frame.** `syncStripFramingGuide()` (`app.js:1609-1631`) shows the aperture: ratio `slots[0].w/slots[0].h` from `strip.js` (fallback 564/504 ≈ 1.12:1) centred in the shown video. Phones capture portrait, iPad/desktop landscape (`sessionOrientation`). A world must survive a centre crop in **both** orientations → per-world focal point + per-orientation asset (§3.2).
- **Settings plumbing:** `DEFAULTS` (`app.js:1-125`), `fillSettingsUI()` (`:1405-1425`), the save-side draft builder (`:1580-1600`) → `EVENT.migrateEventConfig` which **passes through unknown primitive keys** (`event.js:296-306`, `copyPrimitiveFields`). New keys `worldId` / `worldGuestChoice` therefore persist without touching `event.js`.
- **Host defaults live in the Vibe step:** `index.html:807-811` `.field-grid.host-defaults` (Strip frame / Strip finish / Magazine default selects) — the world default and guest-choice toggle go here, nowhere else.
- **Booth Kits are data** (`kits.js`, `applyBoothKit` `app.js:678-703`, `KIT_COPY_FIELDS` `:677`, hidden `#setKitId` `index.html:745`). A kit's default world is one optional field (§3.4).
- **Capability matrix:** `product.js:208-259` — `capabilities(spec)` returns a frozen object per tier; `getCapabilities()` `:261`. Tests pin the key list at `tests/product.test.js:120-160`. "Prices structurally cannot grant capabilities" is the benchmark file — feed it.
- **No build step, no runtime dependencies, no third-party requests.** `privacy.html:46` is a legal promise: *"No third-party scripts, fonts or content are loaded. The booth makes no requests to any other company's servers."* → the segmentation runtime **must be vendored and served first-party** (§2.1). A CDN load would make the privacy page false.
- **Service worker** (`sw.js`): finite precache `ASSETS` list (`:3`), network-first with cache-write only for `CACHEABLE_ASSET_URLS` (`:52-80`); `CACHE="mybishbash-photobooth-v12"` is pinned by `tests/integration-contract.test.js:667`. Vendor WASM (≈12MB) and world photos must be **runtime-cacheable, never precached** (§2.6).
- **Vercel static routing** (`vercel.json`): existing files are served before the `/(.*)`→`404.html` rewrite (that is how `assets/demo-photos.jpg` works today). `.mjs`, `.wasm`, `.tflite` under `vendor/` and `assets/worlds/` need no config.
- **E2E camera:** Playwright runs Chromium with `--use-fake-device-for-media-stream` (`playwright.config.js:6-7`); `tests/e2e/helpers/booth.js:57-67` wraps `getUserMedia` for call counting. The fake feed is a synthetic pattern — segmentation will produce nonsense masks on it; e2e can only assert **pipeline state transitions and the classic path being untouched**, never mask quality.
- **Tests today:** `npm test` = 120/120 (Node `node --test tests/*.test.js`); e2e 4 specs.
- **Vocabulary collision:** `theme.background` / `backdrop` are taken (Vibe themes, Polaroid chrome `polaroid.js:318-323`). The feature vocabulary is **World / Worlds** — never "background" in identifiers, files or copy keys. (Same lesson as Booth Kit vs `TEMPLATES`.)

## 1. Constitution for this programme (violations need a written decision record)

1. **On-device only.** Camera frames, masks and composites never leave the device. The original prompt's "unless technically necessary" is deleted — it is never necessary, and the constitutional Free/Personal invariant forbids it. The privacy page's "no third-party requests" line must remain literally true.
2. **One seam.** Worlds plug in through a single `cameraFrameSource()` function used by the preview, still capture and the Polaroid. No second capture path, no parallel camera.
3. **Classic path byte-identical.** With no world active, every existing function executes the same statements as today. Guarded by: the classic e2e specs unchanged and green, and `capturePhoto`/`freezeCameraFrame` diffs limited to the source lookup.
4. **Data, not code, for worlds.** A world is one object in `worlds.js`. Adding a world (colour, photo, future AI-generated) is a data + asset change, never a code path.
5. **Mechanical gate, undecided price.** `canUseWorlds` exists in the capability matrix from day one; its per-tier value is **provisional** until the D7 pricing ruling and is the *only* place a tier is granted or denied Worlds. Host-test (showcase) never depends on it.
6. **Degrade to classic, never to broken.** Any failure (no WebGL/WASM, model missing, slow device, in-app browser) resolves within a bounded time to the classic camera with one short status line. No spinner that blocks the shutter.
7. **Vocabulary:** World / Worlds. Never "background", never "template".
8. **Sequence by irreversibility:** spike (PB-34) → library + UX (PB-35) → asset pack (PB-36). PB-36 is data-only and must not start until PB-34's numbers pass.

## 2. Shared design (applies to all three packets)

### 2.1 Segmentation runtime — vendored MediaPipe Tasks Vision
- Package `@mediapipe/tasks-vision@1.0.1` (npm, **Apache-2.0**; verified 2026-09-03: `vision_bundle.mjs` 155,439 B; `wasm/vision_wasm_internal.js` 323,377 B; `wasm/vision_wasm_internal.wasm` 11,756,954 B). Model `selfie_segmenter.tflite` (float16, 256×256, **249,537 B**, Apache-2.0) from `https://storage.googleapis.com/mediapipe-models/image_segmenter/selfie_segmenter/float16/latest/selfie_segmenter.tflite`.
- **Vendor into the repo**, committed (not gitignored):
  ```
  vendor/mediapipe/README.md                 ← version, source URLs, licence, the exact copy commands
  vendor/mediapipe/LICENSE                   ← Apache-2.0 text from the npm package
  vendor/mediapipe/vision_bundle.mjs
  vendor/mediapipe/wasm/vision_wasm_internal.js
  vendor/mediapipe/wasm/vision_wasm_internal.wasm
  vendor/mediapipe/selfie_segmenter.tflite
  ```
  Do **not** vendor `vision_wasm_nosimd_internal.*` or `vision_wasm_module_internal.*` (another ~24MB). `FilesetResolver` picks the SIMD build on every browser the booth supports (Safari ≥ 16.4, Chrome, Firefox); on a browser that requests the nosimd file the load 404s → classic fallback (§2.5). The spike **confirms in the network panel** that only the four vendored files are requested; if the bundle requests a different filename, vendor that one instead and update the README.
- Load lazily with a dynamic import from classic script code: `import("./vendor/mediapipe/vision_bundle.mjs")`. Never a `<script>` tag, never at page load.
- Creation (verbatim shape, in `segmenter.js`):
  ```js
  const {FilesetResolver,ImageSegmenter}=await import("./vendor/mediapipe/vision_bundle.mjs");
  const fileset=await FilesetResolver.forVisionTasks("./vendor/mediapipe/wasm");
  const make=delegate=>ImageSegmenter.createFromOptions(fileset,{
    baseOptions:{modelAssetPath:"./vendor/mediapipe/selfie_segmenter.tflite",delegate},
    runningMode:"VIDEO",outputConfidenceMasks:true,outputCategoryMask:false});
  let segmenter;try{segmenter=await make("GPU");}catch(e){segmenter=await make("CPU");}
  ```
  Per frame: `segmenter.segmentForVideo(video,performance.now(),result=>{ const m=result.confidenceMasks[0]; mask=m.getAsFloat32Array(); mw=m.width; mh=m.height; result.close(); })`. `confidenceMasks[0]` is the **person** probability for `selfie_segmenter` (single foreground class). Always call `result.close()`.
- Cold payload ≈ 12.5MB. Budget and the "warming up" state are in §2.5.

### 2.2 `segmenter.js` — the adapter (new file, UMD wrapper like `motion.js`, global `MyBishBashSegmenter`)
Public API, nothing else:
```js
load({timeoutMs=15000})   // → Promise<{ok:true}|{ok:false,reason}>; idempotent; caches the instance; reason ∈ "unsupported"|"timeout"|"load-failed"
isReady()                 // boolean
segment(video,nowMs)      // → {mask:Float32Array,width,height} | null (null while a previous segment is in flight or not ready)
close()                   // frees the segmenter; next load() rebuilds
lastSegmentMs()           // rolling mean of the last 30 segment durations, for the adaptive rule and the diag overlay
```
`load()` guards: `window.isSecureContext`, `WebAssembly`, and `document.createElement("canvas").getContext("webgl2")` (GPU delegate wants it; CPU fallback still allowed) → otherwise `{ok:false,reason:"unsupported"}` without importing anything.

### 2.3 `worlds-live.js` — the compositor (new file, UMD, global `MyBishBashWorldsLive`; pure parts Node-testable)
- `smoothMask(prev,next,alpha)` — pure. EMA over Float32Arrays of equal length; returns `next` unchanged when `prev` is null or lengths differ. Default `alpha=0.55`.
- `coverRect(srcW,srcH,dstW,dstH,focal)` — pure. Returns `{sx,sy,sw,sh}` source rect for a cover-fit that keeps the focal point `{x,y}` (0–1) inside the destination, clamped. This is how a landscape/portrait world lands correctly for any camera aspect.
- `paintWorld(ctx,world,w,h,{orientation,mirror,image})` — draws the world layer at `w×h`. Colour worlds render procedurally (§3.1); photo worlds draw `image` via `coverRect` with the orientation's focal point. **If `mirror` is true, the world is drawn horizontally flipped** (`ctx.translate(w,0);ctx.scale(-1,1)`) — see §0 mirror consequence.
- `createCompositor({width,height,feather=6})` → `{canvas, draw(video,mask,mw,mh,world,opts)}`. Owns three offscreen canvases: `maskCanvas` (mw×mh, alpha = mask×255 written via `ImageData`), `personCanvas` (w×h), and the output `canvas` (w×h). `draw()`:
  1. `paintWorld(outCtx,…)`
  2. `personCtx.drawImage(video,0,0,w,h)`; `personCtx.globalCompositeOperation="destination-in"`; `personCtx.filter="blur("+feather+"px)"`; `personCtx.drawImage(maskCanvas,0,0,w,h)`; reset filter/composite.
  3. `outCtx.drawImage(personCanvas,0,0)`.
  Output size = the video's native `videoWidth×videoHeight` (this canvas *is* the capture source; capture quality = camera quality). The person's pixels are never colour-altered (constitution: no face/body changes).
- Frame loop lives in `app.js` (§2.4), not here — this module has no timers, no DOM lookups, like `motion.js`.

### 2.4 The seam in `app.js`
- Markup: add `<canvas id="worldCanvas" class="world-canvas" hidden></canvas>` immediately after `<video id="video">` (`index.html:599`). CSS: `.camera-wrap>canvas.world-canvas{position:absolute;inset:0;width:100%;height:100%;object-fit:contain;background:#000}` and `.camera-wrap>canvas.world-canvas.mirror{transform:scaleX(-1)}` next to `styles.css:318-319`; `.camera-wrap.world-live>video{opacity:0}` (the video must keep playing and stay drawable — never `display:none`).
- State (next to `let stream=null`, `app.js:361`): `let liveWorld=null, worldPipeline=null, worldStatus="off";` — `worldStatus ∈ "off"|"loading"|"live"|"fallback"`.
- `function cameraFrameSource(){return worldStatus==="live"?$("worldCanvas"):$("video");}`
- Exact diffs: `capturePhoto()` — `const v=cameraFrameSource()` in place of `$("video")` (`:1688`; width/height come from `$("video").videoWidth/Height` still). `freezeCameraFrame()` — draw `cameraFrameSource()` (`:1702`). `captureMovingPolaroid()` — `drawMotionFrame(ctx){compositor.drawLive(ctx,cameraFrameSource());}` (`:1806`). **Nothing else in those functions changes.**
- `startWorldPipeline(sid, world)`: sets `worldStatus="loading"`, `await SEGMENTER.load()`; on `{ok:false}` → `worldStatus="fallback"`, show status line (§2.5), return. Else create the compositor at `video.videoWidth×videoHeight`, toggle `.mirror` on `#worldCanvas` to match `settings.mirror`, add `world-live` to `.camera-wrap`, unhide the canvas, `worldStatus="live"`, and start a `requestAnimationFrame` loop: each frame → `SEGMENTER.segment(video,now)` (skip when null) → `smoothMask` → `compositor.draw(...)`. All loop iterations check `sid===captureSessionId` and stop otherwise.
- `stopWorldPipeline()`: cancel rAF, remove `world-live`, hide canvas, `worldStatus="off"`, `liveWorld=null`. Called from `stopCamera()` and `teardownBoothSession()` (`:1161`). Do **not** call `SEGMENTER.close()` between guests — keep the warm instance for the whole booth run; close only in `teardownBoothSession`.
- **Adaptive rule (mechanical, not a vibe):** if `SEGMENTER.lastSegmentMs()>50` after 30 frames, segment every 2nd frame (reuse the last mask). If measured composite fps stays `<12` for 3 consecutive seconds while live, call `stopWorldPipeline()`, set `worldStatus="fallback"`, show the status line — the shutter keeps working throughout.
- **Warm-up:** when the booth's settings carry a `worldId` (host default) or `worldGuestChoice` is on and the capability allows it, call `SEGMENTER.load()` from `showEventHome()` (`:1275`) — i.e. while the guest is still on the welcome screen — so the 12MB is usually cached before START. Never at landing/marketing page load.

### 3.1 `worlds.js` — the registry (new file, UMD like `kits.js`, global `MyBishBashWorlds`)
```js
var CATEGORIES=[ // order = tab order in the picker
  {id:"colours",name:"Colours"},{id:"switzerland",name:"Switzerland"},{id:"beach",name:"Beach"},
  {id:"hollywood",name:"Hollywood"},{id:"cities",name:"Cities"},{id:"film",name:"Film"}];
var WORLDS=[ /* one object per world */ ];
```
World object — every field required unless marked optional:
```js
{
  id:"colour-bright-pink",        // /^[a-z0-9-]+$/, unique
  name:"Bright Pink",
  category:"colours",             // must be a CATEGORIES id
  kind:"gradient"|"photo",        // the only two renderers in V1; "generated" reserved for the AI packet
  active:true, featured:false, sortOrder:10,
  render:{stops:["#ff2d8a","#ff7ab8"],angle:28,vignette:0.18,grain:0.04},   // kind:"gradient" only
  asset:{landscape:"assets/worlds/beach/tropical-cove-landscape.jpg",          // kind:"photo" only
         portrait:"assets/worlds/beach/tropical-cove-portrait.jpg",
         thumb:"assets/worlds/beach/tropical-cove-thumb.jpg"},
  focal:{landscape:{x:0.5,y:0.45},portrait:{x:0.5,y:0.4}},                    // kind:"photo" only
  source:"",                       // provenance: "own-generated" | "cc0:<url>" | "licensed:<vendor>:<licence-id>"; required non-empty when active && kind==="photo"
  licence:"",                      // human-readable licence line, same rule
  tags:[]                          // optional, free strings (seasonal, wedding, birthday…) for future filtering
}
```
API: `CATEGORIES, WORLDS, WORLD_IDS, find(id), byCategory(id) /* active only, sorted by sortOrder then name */, featured(), validate(world) /* returns [] or error strings; used by tests */`.
**Colours (kind gradient, all active):** bright-pink, soft-pink, purple, blue, sky-blue, green, yellow, orange, red, black, white, gradient-sunset (3 stops), gradient-ocean (3 stops) — 13 worlds.
